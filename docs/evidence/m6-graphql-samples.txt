## 2. Limits
$ { dashboard { payStats(groupBy: COUNTRY, limit: 101) { group } } }
  -> limit must be between 1 and 100
$ { dashboard { distribution(currency: USD, buckets: 30) { count } } }
  -> buckets must be between 5 and 20
$ { dashboard { a: payStats(groupBy: COUNTRY, limit: 100){group} b: payStats(groupBy: DEPARTMENT, limit: 100){group} c: payStats(groupBy: JOB_TITLE, limit: 100){group} } }
  -> Query has complexity of 301, which exceeds max complexity of 200
$ { __schema { types { fields { type { ofType { ofType { ofType { ofType { name } } } } } } } } }
  -> Query has depth of 9, which exceeds max depth of 8
$ { dashboard(filters: {country: XX}) { headcount } }
  -> Argument 'country' on InputObject 'DashboardFilters' has an invalid value (XX). Expected type 'CountryCodeEnum'.
$ { dashboard { distribution { count } } }
  -> Field 'distribution' is missing required arguments: currency
